ПРИЛОЖЕНИЕ «МАССАЖ ВАРНА»

Это готовое PWA-веб-приложение.
1. Загрузите ВСЕ файлы этой папки на HTTPS-хостинг.
2. Откройте получившуюся ссылку на iPhone.
3. В Safari: Поделиться → На экран «Домой».
4. Приложение запускается отдельно от вкладки браузера.
5. Кнопка записи ведёт прямо в Telegram: https://t.me/vycheslavBG

Для Android браузер может показать кнопку «Установить приложение» автоматически.
